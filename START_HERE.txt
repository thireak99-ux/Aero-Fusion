AEROFUSION — INTELLIJ QUICK START

1. Extract the ZIP completely to a normal folder, for example:
   C:\Projects\AeroFusion
   Do not open or run the project while it is still inside the ZIP.

2. Open IntelliJ IDEA > Open.
   Select the extracted AeroFusion folder (the one containing pom.xml).
   Open it as a Maven project if IntelliJ asks.

3. File > Project Structure > Project > SDK: choose JDK 21.
   If it is missing, choose Add SDK > Download JDK and choose version 21.
   Use a full JDK, not a JRE. Language level: 21, without preview features.

4. Allow Maven to download dependencies. Internet is needed for this first setup.
   If dependencies stay red, open the Maven tool window and click Reload All Maven Projects.

5. Run the included configuration: AeroFusion - Run.
   Alternative: Maven tool window > Plugins > javafx > javafx:run.
   Alternative terminal command, if Maven is installed:
       mvn clean javafx:run

6. In the login screen, choose a role > Fill demo account > Sign in.

TEST THE COMPLETE PROGRAM WITHOUT EXPIRED DATES
1. Sign in as Airport Manager > Demo & time controls.
2. Select a current flight, or click Add fresh demo week for an unused set.
3. Choose "2h before departure: full workflow" > Apply preset.
   The visible DEMO TIME label confirms that time is paused.
4. Note the selected flight number and aircraft. Use Open another login for
   each role, then follow docs/DEMO_WALKTHROUGH.md in order.
5. Use docs/TEST_EVERY_FUNCTION.md for the remaining buttons, time boundaries,
   error cases, reports, tracking and disruption scenarios.
6. Click Use computer time when finished. Restarting also uses computer time.

IMPORTANT DEMO DETAILS
- The schedule uses Cambodia time (UTC+7).
- The first launch creates 28 flights across seven days, starting about four
  hours from the computer's current time. Initial flight numbers start at AF101.
- Startup and open dashboards add a fresh week automatically when no flight
  with a free seat is bookable within the next 24 hours. Old records are kept.
- While demo time is paused, automatic additions pause too. Add a fresh demo
  week yourself if you need flights around a custom date.
- Flight board offers Upcoming and active, Selected date and All dates / history.
  Operations also has Include past flights. Passenger search accepts future dates.
- Every time-control action closes counters and revokes ATC clearance. Reopen
  counters and assign/grant current runway slots after changing time.
- Aircraft initially need a Maintenance inspection before Boarding is allowed.
- Card payments, baggage payments and refunds are simulated. Click Fill demo card.
- The demo card expiry follows the app's current date instead of a fixed year.
- Data is saved automatically to data/airport-csv/current/*.csv in the project folder.
- Flight board changes are immediate across open windows in this app.
- On Flight board, Flight tracking, Boarding pass and Demo controls, use the top
  navigation: Back to dashboard, Flight board or Flight tracking. Managers can
  also jump to Demo controls. Returning keeps the dashboard on the same tab.
- Opening another page from the dashboard reuses its workspace window, so the
  board, tracking and boarding pass do not pile up as separate windows.
- Click Open another login to demonstrate multiple roles together.
- Demo tracking works offline after Maven has downloaded dependencies.
- Optional live OpenSky tracking needs internet and is subject to availability/rate limits.

KEEP DATA FROM YOUR PREVIOUS VERSION
Close all windows of the previous app. Keep a backup, then copy its entire data
folder into the extracted AeroFusion folder before starting this version.
Existing accounts, bookings and flight dates stay unchanged. New schedules are
added when the old ones have expired. The old airport.db is imported once
and kept as a backup. You do not need to delete your saved data.
The existing demo email addresses remain valid; use Fill demo account.

For a new demonstration with the same saved CSV files, use Add fresh demo week.
Use one running application and Open another login: demo time is shared by its
windows, not by separately launched application processes.
